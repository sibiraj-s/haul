Add a `haul` command-line tool: `haul add <link>…` opens the Add panel with the links filled in, and `haul add < links.txt` reads them from a file. It ships inside Haul; choose Haul → Install Command Line Tool… for the Terminal command that adds it to /usr/local/bin. Once it’s installed, the same item becomes Uninstall Command Line Tool…
