Add a `haul` command-line tool: `haul add <link>…` opens the Add panel with the links filled in, and `haul add < links.txt` reads them from a file. Choose Haul → Install Command Line Tool… to put it in ~/.local/bin, no password needed; if your shell doesn't look there yet, Haul shows the line to add and can add it to ~/.zshrc (or your shell's file) for you. The command comes from inside Haul, so it updates with the app, and the same menu item uninstalls it
