Download over several networks at once: with Multi-network downloads on in Settings → Network, each download splits its connections across Wi‑Fi, Ethernet and USB tethering, and a badge in the header shows each network's speed and the total speed-up. It's off by default, and Haul offers it once when it finds more than one network to use. Metered networks such as a phone's hotspot are only used when Pause on Personal Hotspot is off, and nothing changes while a VPN or proxy is on. Each network is checked to serve the same file before it's used, and one that can't reach the file or serves another version of it is left out while the download carries on over the rest
